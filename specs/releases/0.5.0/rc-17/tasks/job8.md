# Job 8 — the ref gate REBUILD: a zero old sha is not a creation (FR14, R3)

**Status:** Draft

- **The bug.** `git pack-refs --all` hands the reference-transaction hook a zero old sha for refs that already exist, and `dadaia_workspace/hooks/ref_transaction.py` reads `zero old and non-zero new` on `refs/heads/wt/*` as a creation: it prints `[ref-gate] BLOCKED refs/heads/wt/0.5.0/rc-17/wt-rc` and a fix line (`worktree new` on an existing tree) that cannot run, a Stall. Caused by the shell-spelling REBUILD `e2830acf2` (`os-boundary-shell-spelling-has-several-producers-and-a-lossy-quoter`); it correlates `ref-gate-admits-a-forced-move-git-hands-a-zero-old-sha` (six fixes in the window on the same unit).
- **Structural cause and REBUILD.** Two deciders answer "does this zero-old line name a creation?": the hook's `main`/`_creation_refusal` (zero old means creation) and `cli/commands/ci.py ref_gate_check` (:265-267, zero old means "re-read the ref"). One decider remains, in the hook module: the ref is read once, an existing ref is an update (it passes, as the module's documented contract says: "updating it passes"), and only a missing ref is a creation. `ref_gate_check` receives the resolved old sha and its re-read is deleted. Prior diffs to read first: the `fix_sha` of `ref-gate-admits-a-forced-move-git-hands-a-zero-old-sha` and the other five window fixes on these two files (`git log -p` on each), and `e2830acf2`. Contract tests those fixes hardened stay unloosened, among them `test_ci__cli_ci.py` `test_ref_gate_refuses_a_zero_old_line_for_an_existing_work_ref_off_origin` (40 and 64 zeros): the sr returns the gap to the main thread before coding if a design cannot keep it green.
- **The follow-ups ride along** (backlog `ref-gate-hardening-follow-ups`, read in `specs/backlog/BACKLOG.json`): `ref_gate_check` catches a fault of `_audit_only` inside the decision (defence in depth: today a decided BLOCK becomes the hook's fail-open); the function-local `ZERO_SHA` import at `ci.py:99` joins the module-level one; the header words of `hooks/ref_transaction.py` state the contract the law states (`worktrees/AGENTS.md` head: creating a `wt/*` branch is refused, an existing one's update passes). The entry's not-reproduced SHA-length patterns and its two operator questions are not scheduled (PLAN §3 Q-R3).
