Paths are repository-relative to `repos/dadaia-workspace/`; `S/` = `dadaia_workspace/public/skills/`, `K/` = `S/dd-bug-resolution/scripts/`, `PP/` = `dadaia_workspace/public/`, `P/` = `dadaia_workspace/`. Design and evidence: PLAN section 1 (the row each task names), section 4 (consumers), section 5 (hazards). The job opens when Job 3 has merged into the `wt-rc`; tasks with disjoint `W:` run together, at most 4 agents; a task whose `waits on` names another shares a file with it or consumes its output.

Wave IV. Each task that fixes a recorded bug, or lands on a unit already fixed in the window, is the REBUILD of that unit under `refactor(bugs): <id> - REBUILD <unit>`; the held lanes' RED tests feed R45 and R46 and their `fix(bugs)` commits do not land. A behaviour is a RED task, then its implementation tasks, each its own dispatch (`dd-release-definition` section 5). Serial chains: R40 (J4.T1-T4), R42 (T5-T8), R43 (T9-T10), R44 (T11-T15), R46 (T21-T24), R47 (T19-T20). A producer and the tests that pin it change in the same task; the RED tasks add rows to existing contract files or create the one new file they name. J4.T33 owns `CANON_AT[13]` and `shipped-hashes.json` for the wave.

**Definition of done (each task).** `python scripts/ci.py job` passes; the test directories `python scripts/impact.py <the task's W:>` prints pass; for a fix, the first-pass sweep grep with its hit count (ADR 0280 clause 2); the own-diff self-check of `dd-release-implementation` section 3. The gate is the repo `verify:` line, unchanged: no preflight, no new gate, never the full CI line. A task that finds a pin its `W:` does not name stops and amends this file in a shape-5 commit, then continues; it never edits outside its `W:`. Net production lines are at most 0 per task, or the outcome states the reason.

**Sweep greps.** for each fix, the sweep of its pattern across the context's repos with its hit count, stated in the review request; `git grep -n -e "--sha" -- dadaia_workspace/public/skills/dd-release-implementation/scripts` prints 0 after J4.T12; `git grep -nE "\bfix_files\b" -- dadaia_workspace/public/skills` prints only derived-on-read uses after J4.T7.
