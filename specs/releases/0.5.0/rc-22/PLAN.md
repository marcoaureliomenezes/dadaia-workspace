## 2. Jobs, sizes and dispatch

**The cut.** Job 1 law (ADR 0280's text homes, `SLOP.md`); Job 2 text (one owner per fact); Job 3 code duplicates and kernel functions; Job 4 one REBUILD per unit, the R40, R42, R44 and R46 chains serial inside it; Job 5 cross-cutting test REBUILDs; Job 6 eval graders; Job 7 the agentic scorecard. A behaviour is a RED task then its implementation tasks, each its own dispatch and `wt-task` tree (`dd-release-definition` section 5). - **Reproject.** Every job changes projected sources: after each job's merge the main thread runs `public install`, then `doctor`, on the instance (act AP). The instance runs the projected copy of the skill scripts, so a kernel change is live in the instance only after AP.
