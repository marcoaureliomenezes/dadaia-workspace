# Job 3 — worktree pause and resume (FR3, ADR 0271)

**Status:** Draft

Wave 1, waits on —. Paths are repository-relative to `repos/dadaia-workspace/`. Design and evidence: PLAN §1, §1.1, §2 (seams R3, R5).

- **Writer (T7).** `_worktree_pause.py` is a new unit; `_worktree_end.py` is not edited, its `_target`, `_refuse_dirty`, `_open_children`, `ours`, `kind_of` are imported. It exposes `write_bundle(repo, branch, dest)`: `git bundle create <dest> <branch> --not --remotes=origin`, then `git bundle verify`; on any failure it leaves nothing at `dest`. Pause and Job 5's export call it and no other bundle writer exists. `dest` is `.dadaia/dist/<repo>/<name>.bundle`, `<name>` the tree name, built with `as_posix()`.
- **Pause (T7).** Refuses, nothing touched, in this order: a job or task path; a dirty tree (fix: commit first); a tree holding ignored files (`git status --porcelain --ignored`; fix: delete them or commit; no `--keep`/`--drop`); a `wt-rc` with an open tree below it; a failed or empty bundle (git refuses an empty range, so a tree whose commits origin already holds refuses with `merge`'s line). Then `git worktree remove <tree>`, then `update-ref -d refs/heads/wt/<name>` under the CLI marker (`_git.git` sets `DADAIA_WT`). No commit, no push; a pushed branch loses only its local ref, origin's stays.
- **Resume (T8).** Refuses with one fix line when the local branch exists or no bundle sits at the path. Else `git fetch <bundle> <branch>:<branch>` (marker set), `git worktree add`, the level-folder `AGENTS.md` through `_worktree_new`'s level-folder writer, then deletes the bundle and its empty `dist/<repo>/` folders. No upstream is set.
- **List (T9).** `paused_rows(root)` reads `.dadaia/dist/<repo>/**/*.bundle`; each row has `state` and `kind` `paused`, `path` the tree path `resume` takes, `warn` false, `exit` the `resume` line, `fix` empty. `worktree.py`'s `list` appends them. `_release_phase._refuse_open_worktrees` keeps only `kind != "rc"`, so a paused row already refuses closure; T4 pins it with no edit there.
- **Dead and delete (T10).** `_dead_preflight`'s `held` skips `state == "paused"`; `delete` refuses while `dist/<repo>/` of a repo of the context holds a `.bundle`, fix: resume it or move it.
- **Zone (T11).** The `dist` canon admits `<registered slug>/` by the registered-slug mechanism `verdict()` already uses for its other zones (no `*`), the soft JSON and the hard archive (names: PLAN §2); `doctor --fix` never moves a bundle of a registered repo.
- **Reproject.** After this job merges the main thread runs `public install` and `public doctor` (the projected `worktrees/AGENTS.md`, the `dist` row of `.dadaia/AGENTS.md`).
