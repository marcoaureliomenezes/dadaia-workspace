# Job 5 — one decider of a repo's context, under the fix-cite rule (FR3, R3)

**Status:** Draft

Wave 2, waits on Job 1 (`_specs.py`). Paths are repository-relative to `repos/dadaia-workspace/`; `S/` = `dadaia_workspace/public/skills/`. Design and evidence: PLAN §1, §1.1, §1.2, §3 (R3 cost).

- **Shape (T2).** `_specs.py` owns the one answer: `context_row(root, repo)` runs `context list --json` through `run_cli` (the one spawn, `_specs.py:45-57`) and returns the row owning `repo` (main or associated; none for a repo no context owns); `context_repos(repo)` returns `[repo]` plus the associated checkouts that exist, built on it. `_git.context_repos` (`_git.py:257-267`) and its raw read of `.dadaia/states/spec_contexts.json` go; `fix_commit` takes the repo list from its callers (`_bugs_check.py:199-200` already holds both calls; `_bugs_write.py:38` and `bugs.py:172` pass `_specs.context_repos(…)`). `_stats._context` (`_stats.py:58-69`) goes: `table` reads the name and integration branch from `context_row`. Degradation: no workspace, or no workspace CLI at the root, gives `[repo]` alone (a fresh clone must still `check`); a CLI that runs and fails refuses with its own `fix:` line, which is the bug's "refused with a fix line, never an AttributeError".
- **Shape (T2, retirement).** `fix_commit` (`_git.py:275-292`) retires by count, not by set: a commit subjected `Revert "<S>"` retires exactly one older commit subjected `<S>` (the nearest), so two same-subject fixes with the newer reverted return the older. `Reapply "S"` stays read as a revert of a revert (`_canon`, `:270-272`), and a retired revert registers nothing.
- **Cost.** One more spawn per `bugs.py check`/`resolve` that cites a fix. T2 times one `bugs.py check --specs` on this repo before and after and reports both in the hand-back; the PLAN §3 rule applies if the added time exceeds the job gate's per-run share.
- **Lineage (main thread, in this job's `wt-main`).** Before T2: `bugs.py update --set caused_by=worktree-sync-orphans-the-fix-sha-a-lanes-resolve-cites` on `bug-skill-registry-reader-crashes-on-a-bad-row` and on `fix-cite-retires-the-older-same-subject-fix`; one group fix commit, `refactor(bugs): bug-skill-registry-reader-crashes-on-a-bad-row, fix-cite-retires-the-older-same-subject-fix — REBUILD the fix-cite rule: …`; `resolve --caused-by` each after.
- **Contract tests that stay green, unloosened (AC3.2):** `fix_commit`'s in `test__git.py` (a `Reapply "S"` read as a revert of a revert, a group line, a commit HEAD reverts that is skipped, an associated repo read), and the tests of `worktree-sync-orphans-the-fix-sha-a-lanes-resolve-cites` in `test_bugs.py`; the stats tests in `test_verdict.py`.
