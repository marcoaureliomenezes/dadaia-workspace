# PLAN stage — dd-grill-me

After the PLAN, only when it holds a technical choice. Two questions, answered by inspection first.

1. Does the PLAN contradict an accepted ADR? Name the record and the line; the operator chooses: change the PLAN, or supersede the record.
2. Does it carry a technical decision past the ADR threshold (see the adr reference)? Then ask it with that reference's question bank, and record it as a proposal before the PLAN is approved.

Neither: no session.
