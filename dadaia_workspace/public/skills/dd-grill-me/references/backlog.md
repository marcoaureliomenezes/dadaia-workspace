# Backlog stage — dd-grill-me

Before a demand becomes a backlog entry. Inspect first; ask only what inspection cannot settle.

1. Is it a decision at all? A wish with no chooser, no cost of waiting and no alternative is a note: say so and stop.
2. Is the problem measured? Ask for the number, the incident or the command that shows it; none found by inspection means the first entry is the measurement.
3. Feature or bug? Does the tool break a contract it documents? Yes: a bug, filed by the bug law. No: a feature.
4. What is the scope? One outcome, what is out, and the demand's smallest form that still serves it.
5. Does an entry, a bug or a shipped feature already cover it? Merge into it, never duplicate.

Record: the answers go into the entry's description in the same turn, the operator's words kept.
