# [PLUGIN REQUIRED] devops-engineer

`devops-engineer` is a plugin agent, not part of the 9-agent core roster
(constitution §14). It carries no behavior until its pack is installed in this
workspace.

The `devops` pack is not installed here — run `dadaia plugin install devops`
(the command and packs ship in v0.1.60), or route this task to the operator.
Once installed, the real `devops-engineer` handles CI/CD and deploy work
directly.
