# [PLUGIN REQUIRED] design-specialist

`design-specialist` is a plugin agent, not part of the 9-agent core roster
(constitution §14). It carries no behavior until its pack is installed in this
workspace.

The `frontend-design` pack is not installed here — run
`dadaia plugin install frontend-design` (the command and packs ship in v0.1.60),
or route this task to the operator. Once installed, the real `design-specialist`
handles design/UX work directly.
