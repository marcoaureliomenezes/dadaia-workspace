# Sessao 5: Agents e Multi Agent Orchestration Quick Start

Esta sessao fecha a trilha base com um ponto critico: entender o que de fato e um agent e quando faz sentido sair de um unico agent para alguma forma de orchestration.

O objetivo nao e vender complexidade. E ensinar criterio.

## O que voce vai dominar

1. A diferenca entre chat, workflow fixo e agent de verdade.
2. Os componentes minimos de um agent confiavel.
3. Os principais orchestration patterns e quando usar cada um.
4. Os riscos operacionais: memoria, contexto compartilhado, observabilidade, custo e governanca.

## Resultado esperado

Ao final, voce deve conseguir decidir entre um single agent, um workflow fixo, um orchestrator com specialists ou um arranjo multi-agent mais elaborado, sem cair na tentacao de complicar a arquitetura antes de ter um problema que realmente exija isso.
