
# Sessao 4: SDD Quick Start

Esta sessao apresenta o Spec-Driven Development como disciplina de trabalho para engenharia assistida por IA.

O foco aqui nao e romantizar specs. E entender quando elas aumentam confiabilidade, como devem ser escritas e como se conectam ao fluxo real do `dadaia-workspace`.

## O que voce vai dominar

1. O que muda quando a especificacao deixa de ser burocracia e vira artefato operacional.
2. Como diferenciar `spec`, `memory bank` e instrucoes persistentes.
3. Como usar `SPEC.md`, `PLAN.md`, `TASKS.md` e `constitution.md` sem transformar o processo em teatro documental.
4. Como encaixar SDD no runtime e na governanca do Dadaia Workspace.
