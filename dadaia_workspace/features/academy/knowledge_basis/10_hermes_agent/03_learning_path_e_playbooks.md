# 03. Learning Path e Playbooks

Consulta oficial: 2026-05-09.

## Como usar a pagina Learning Path

A pagina organiza trilha por:

- nivel de experiencia;
- caso de uso;
- features-chave.

Nao tente ler tudo na ordem. Escolha por objetivo de operacao.

## Trilha por perfil

### Iniciante

Objetivo: setup e conversa basica.

Ordem recomendada:

1. Installation
2. Quickstart
3. CLI Usage
4. Configuration

### Intermediario

Objetivo: bot + recursos avancados.

Ordem:

1. Sessions
2. Messaging
3. Tools
4. Skills
5. Memory
6. Cron

### Avancado

Objetivo: extensao e contribuicao.

Ordem:

1. Architecture
2. Adding Tools
3. Creating Skills
4. RL Training
5. Contributing

## Playbooks por caso de uso

### Quero um assistente de coding no terminal

- complete quickstart;
- valide code execution e context files;
- refine tips/tricks para seu ambiente.

### Quero bot em Telegram/Discord

- setup baseline;
- configurar canal;
- revisar seguranca;
- testar sessao/reset e continuidade.

### Quero automatizar tarefas

- validar cron somente apos baseline;
- adicionar batch/delegation com criterio;
- monitorar consumo e falhas de rotina.

## Heuristica de maturidade

Voce esta pronto para camada seguinte quando:

- consegue diagnosticar falha sem tentativa cega;
- consegue explicar onde vive cada tipo de configuracao;
- consegue resetar para estado saudavel em poucos passos.
