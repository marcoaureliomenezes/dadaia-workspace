
# Sessao 3: Open Code Quick Start

Esta sessao apresenta o Open Code como ambiente agentic programavel, com foco em CLI, commands customizados, rules, skills e controle de permissao.

O objetivo principal aqui e entender por que o Open Code e especialmente forte quando voce quer transformar workflows recorrentes em configuracao reutilizavel.

## O que voce vai dominar

1. Como o CLI, o TUI e o modo `run` se complementam.
2. Como criar commands customizados com markdown e frontmatter.
3. Como `AGENTS.md`, `opencode.json` e compatibilidade com `.claude` entram no mesmo sistema.
4. Como tools e permissoes moldam o comportamento do agente.

## Resultado esperado

Ao final desta sessao, voce deve conseguir usar o Open Code em modo interativo e nao interativo, criar um command customizado que referencie arquivos reais do projeto e entender como compatibilizar o ambiente com convencoes ja existentes em `.claude/`.
