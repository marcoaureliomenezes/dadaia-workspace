
# Sessao 2: Claude Code Quick Start

Esta sessao apresenta um modelo mental correto para trabalhar com Claude Code em projetos reais, com foco em contexto, comandos, memoria, ferramentas e operacao segura.

O objetivo nao e decorar a lista inteira de comandos. E entender como usar Claude Code com disciplina suficiente para produzir resultado confiavel em codebase real.

## O que voce vai dominar

1. Como Claude Code enxerga contexto, memoria e instrucoes persistentes.
2. Como os slash commands aceleram fluxos recorrentes.
3. Como as tools influenciam seguranca, verificacao e qualidade das mudancas.
4. Como evitar o erro classico de usar o agente sem framing suficiente.
