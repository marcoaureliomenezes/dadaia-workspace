# Sessao 8: Pi Agent

Consulta oficial: 2026-05-09.

Esta sessao apresenta o Pi como um harness de coding minimalista e extensivel.
A ideia central nao e decorar comandos; e saber operar o Pi com previsibilidade,
controle de contexto e custo de sessao.

## O que voce vai dominar

1. Como iniciar o Pi do zero com setup seguro.
2. Como operar no dia a dia com sessoes, slash commands e contexto.
3. Como customizar Pi via extensions, skills e packages sem perder governanca.
