Phase P11b wires the Option C install call site and verifies manifest parity for data/AGENTS.md.

AGT-r2-35 - Dispatch install call site to _install_workspace_guardrail_pair

The install() method in FileSystemPublicAssetManager previously called self._install_agents_md(), which wrote only one file (workspace-root/AGENTS.md) via the legacy path. Under Option C, when agentic_dir/data/AGENTS.md is present, the method now calls _install_workspace_guardrail_pair() instead, which fans the single source out to all four required destinations: workspace-root pair plus one pair per marker-bearing consumer repo.

The templates/AGENTS.md scaffolder path is preserved intact via an else branch that falls back to the legacy _install_agents_md() call when data/AGENTS.md is absent.

AGT-r2-36 - Manifest update for Option C

After P11a rewrote data/AGENTS.md, running dadaia public stage recomputed the SHA-256. The manifest now reflects the post-P11a content hash. data/CLAUDE.md is absent from the manifest (Option C invariant: there is no second source file).
