Function signature and behavior

New module-level functions

def _install_workspace_guardrail_pair(
    source: Path,
    workspace_root: Path,
    force: bool,
    installed: list[str] | None = None,
) -> None

Behavior per ADR Items 2/4/5 + R13/R14:

  1. Reads source bytes; always writes to workspace_root/AGENTS.md and workspace_root/CLAUDE.md.
  2. Enumerates workspace_root/repos/; qualifies dirs with BOTH .dadaia/ AND .dadaia/agentic/ (R13). Non-qualifying dirs emit [skip] <path> (no .dadaia/ marker) to stderr.
  3. For each qualifying consumer, reads .dadaia/agentic/manifest.json. If package_version matches _package_version(), emits [skip] <path> (self-projection — package_version=<v>) to stderr and skips (R14).
  4. For non-self consumers, writes AGENTS.md and CLAUDE.md byte-identical to source.
  5. Never raises on missing or unexpected paths.
def _doctor_guardrail_pair(
    source: Path,
    workspace_root: Path,
) -> list[str]

Emits and returns parity lines for root pair + each qualifying consumer pair. Labels: root:AGENTS.md, root:CLAUDE.md, repos/<slug>:AGENTS.md, repos/<slug>:CLAUDE.md.

Helpers added

def _consumer_repos_for_root(workspace_root: Path) -> list[Path]
def _is_self_repo(consumer: Path) -> bool

_runtime_expectations extension (AGT-r2-26)

Added immediately after the existing root:AGENTS.md yield:

yield (agents_md, workspace_root / "CLAUDE.md", "root:CLAUDE.md", False)
# Consumer-repo parity (R13 + R14): one pair per marker-bearing repo.
for consumer in _consumer_repos_for_root(workspace_root):
    if _is_self_repo(consumer):
        continue
    slug = consumer.name
    yield (agents_md, consumer / "AGENTS.md", f"repos/{slug}:AGENTS.md", False)
    yield (agents_md, consumer / "CLAUDE.md", f"repos/{slug}:CLAUDE.md", False)

Security checklist

OWASPRelevanceAction taken
A01 — Broken access control File writes to consumer repos could overwrite operator-authored files. R13 marker gate: only dirs with both .dadaia/ AND .dadaia/agentic/ receive writes. R14 self-skip prevents overwriting the dadaia-workspace source tree.
A03 — Injection Consumer slug comes from filesystem iteration, not user input. consumer.name is a plain directory name from Path.iterdir(); no shell call, no SQL, no traversal possible beyond the repos/ subtree.
A04 — Insecure design Nested operator-authored pairs (services/CLAUDE.md) must not be touched. Installer only writes to workspace_root/ and repos/<slug>/ — never recurses into subdirectories like services/. ADR Item 5 verified by test case 5 (nested-pair non-interference) in the xfail suite.
A09 — Insufficient logging Skip/self-skip decisions should be auditable. All skip cases write to stderr with structured prefix ([skip]). No sensitive data logged.
