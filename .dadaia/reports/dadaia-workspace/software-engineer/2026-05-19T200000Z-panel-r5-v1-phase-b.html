Bug fix: SQLite threading

The ThreadingHTTPServer dispatches each HTTP request to a worker thread. A SQLite connection created in the main test thread raises sqlite3.ProgrammingError: SQLite objects created in a thread can only be used in that same thread when accessed from worker threads.

Fix applied (test-only, does not touch production code): sqlite3.connect(str(db_path), check_same_thread=False) in _FixtureTelemetry.__init__. The fixture database is read-only in tests, so cross-thread sharing is safe.
