Key design decisions

  • Real PanelService wired to real .dadaia/agentic/agents/ and .dadaia/agentic/workflows/ files — no mocks or overrides for canonical data.
  • Stub TelemetryService (fake) injects controlled AgentListResult with one "active" agent (1 day ago) and one "inactive" agent (400 days ago) to test status computation against the active_window_days cutoff.
  • Cache invalidation test: creates an isolated temp workspace, writes workflow v1, fetches detail (populates in-memory cache), then overwrites with workflow v2 and advances mtime by +2 seconds via os.utime. The second fetch must return v2 because the (path, mtime, size) cache key has changed.
  • URL-encoded backslash (%5C) in static names results in 404 not 400 — documented as expected behavior because the dict lookup fails before any filesystem I/O, satisfying the security requirement without false assertions.
