NS10 rescission rationale

The prior NS10 stated "workspace CLAUDE.md stays untouched, contains redacted-infra/redacted-infra". This was architecturally wrong: it conflated the file's contents with the file's ownership. The correct model:

  • Workspace-root CLAUDE.md is lib-owned (projection from dadaia_workspace/public/data/CLAUDE.md) — it IS touched by this release, but only via the projection mechanism, not by hand-edit.
  • Workspace-root AGENTS.md is also lib-owned (already manifest-tracked today; CLAUDE.md is added in this release).
  • Both files contain lib-general guardrails ONLY; domain content lives in operator-managed services/.

The replacement NS10 text now clarifies the actual not-in-scope item: the services/CLAUDE.md + services/AGENTS.md pair is NOT lib-projected. It lives in operator-owned space, never in dadaia_workspace/public/, never in .dadaia/agentic/manifest.json, never overwritten by dadaia public install.
