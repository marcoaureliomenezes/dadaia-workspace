Invariants honoured

  • Zero new Python deps — pyproject.toml unchanged (no additions).
  • Zero new npm deps — panel is pure HTML/CSS/JS strings in _assets.py.
  • Panel binding stays 127.0.0.1 — no remote exposure introduced.
  • scan command is read-only — never auto-kills, never auto-registers, never writes.
  • T1 privacy (telemetry allowlist) untouched — scan reads only /proc/<pid>/cmdline + /proc/<pid>/cwd (same data ps exposes).
  • Backwards-compat — resolver returns the same path for already-correct workspaces; /api/servers payload adds unregistered key, never breaks existing keys.
  • brand-identity-v1 alignment — LAN warning badge uses var(--color-alert, #f7af63), the canonical alert token.

Follow-up candidates (registered in candidates.md)

  • Port range validation in register() — out-of-range silent accept (cosmetic, doesn't cause invisibility).
  • dadaia server adopt --port N — interactive registration of a detected orphan.
  • Auto-cleanup of orphans on workspace shutdown (signal handler).
  • Cross-host registry visibility (mDNS/CRDT) — overengineering for v1.
  • The existing spec-context-isolation hotfix candidate (MEDIUM) is independent and remains open.
