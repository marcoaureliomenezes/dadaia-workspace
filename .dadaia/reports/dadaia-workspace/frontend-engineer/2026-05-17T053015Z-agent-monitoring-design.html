5. Acessibilidade

5.1 Correcoes necessarias no panel atual

O views/index.py atual tem lacunas em relacao ao padrao WAI-ARIA Tabs Pattern (WCAG 2.1 AA):

Elemento atualProblemaCorrecao
<nav class="nav-tabs"> Falta role="tablist" Adicionar role="tablist" ao elemento nav
<section id="section-..."> Falta role="tabpanel" e aria-labelledby Adicionar role="tabpanel" + tabindex="0" + aria-labelledby="tab-{id}"
Botoes de aba Falta id nos botoes (para aria-labelledby) e navegacao por setas Adicionar id="tab-{section}"; JS deve capturar ArrowLeft/ArrowRight/Home/End
Cards de agente (futuros) Toggle "Show sessions" precisa de aria-expanded + aria-controls Botao toggle: aria-expanded="false" + aria-controls="sessions-{agent_id}"; painel: id="sessions-{agent_id}"
Barras de proporcao de custo Elemento puramente visual sem equivalente textual Adicionar aria-label="X% do custo total" no elemento da barra
Chips de agente em Workflows Chips sao botoes de acao, nao links Usar <button> com aria-label="Filtrar por agente: {nome}"; foco visivel obrigatorio

5.2 Contraste minimo (WCAG AA)

Com a paleta nova mapeada abaixo, verificacoes criticas de contraste:

  • Texto principal (#222222) sobre fundo (#fafafa ou branco): ratio ~14:1 — passa.
  • Texto de aba ativa (#111111) sobre branco: ~18:1 — passa.
  • --color-accent = #9cddc8: NAO usar como cor de texto sobre branco (ratio ~2.1:1 — falha AA). Uso restrito a decoracao, borders, badges de fundo com texto escuro sobreposto.
  • Badges de texto sobre #9cddc8: texto deve ser #111 (ratio ~7.1:1 — passa).
  • Muted text (#666666) sobre branco: ratio ~5.7:1 — passa AA.
  • Custo em destaque (#633d2e sobre branco): ratio ~8.1:1 — passa AAA.

10. Restricoes Cumpridas

  • Zero deps npm: todo o JS e vanilla, inline. Sem bibliotecas de charting, sem React, sem build.
  • Sem build step: CSS e JS continuam como strings Python em _assets.py. Nenhuma mudanca no pipeline.
  • Transcripts privados: nenhum endpoint proposto expoe content, text, ou mensagens. /api/agents e /api/workflows servem apenas agregados, contagens e metadados.
  • Bind 127.0.0.1: nenhuma mudanca proposta no binding. O frontend nao tem opiniao sobre isso.
  • OWASP A03: todos os valores inseridos no DOM pelo JS passam por escHtml() (ja implementado em PANEL_JS para /api/servers; padrao a seguir para /api/agents e /api/workflows).
  • OWASP A07: nenhum link externo novo proposto. Se chips de workflow apontarem para URLs externas (improvavel), regra rel="noopener noreferrer" se aplica.
  • Reuso de padrao de PANEL_JS: o JS de tab-switching sera estendido, nao reescrito. O fetch pattern de /api/servers e o template para /api/agents.
